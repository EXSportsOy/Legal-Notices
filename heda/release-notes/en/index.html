Version 1.3.0: backups, manual health data, and premium reliability

Production release · 2026-08-20

New features

  • Encrypted backup and restore — export your data to a password-protected .hedabak file and restore it on any device.
  • Manual health data entry — log sleep, steps, exercise, and heart rate by hand when Health Connect data isn't available, with support for editing and merging with synced data.
  • CSV import — import health data from a CSV file, with a mapping step to match your columns.
  • Redesigned Health tab — health data and trends now have their own tab in Analysis.
  • In-app updates — the app can now download and prompt to install updates in the background instead of sending you to the Play Store.
  • Legal acceptance dialog — the Privacy Policy and Disclaimer are now presented for acceptance at startup, and re-shown whenever their terms change.

Improvements

  • Fixed several situations where Premium incorrectly showed as locked or failed silently (network issues, expired sign-in session, restore flows); retry now shows a clear error message and spinner instead of failing quietly.
  • The daily recommendation reminder is now anchored to 09:00 local time and no longer repeats unnecessarily.
  • The calendar's "+" button is now more visible.
  • Added an Imprint link to Settings and a TMG §5 Impressum section to the Privacy screen (German legal requirement).
  • Removed the redundant Disclaimer line from the Settings main screen (now covered by the legal acceptance dialog).
  • The "most common triggers" statistic is now shown on two lines for readability.

Bug fixes

  • Fixed text-encoding corruption in Nordic and several other language translations, including restoring correct characters in sign-in screens across six languages.
  • Fixed Polish button and label wording issues.

Updated terms. The Privacy Policy and Disclaimer were revised on 2026-08-19. You'll be asked to review and accept them again after updating.

Version 1.0.4: wellness classification and copy refinements

Production release · 2026-05-18

Improvements

  • Wellness re-categorisation — app store copy and in-app wording updated throughout all supported languages to position Heda clearly as a wellness app. This keeps categorisation on Google Play consistent and avoids any medical-device interpretation.

Version 1.0.3: bug fixes and stability

Production release · 2026-05-18

Bug fixes

  • Account deletion — the deletion flow no longer crashes if sign-out fails after a remote account delete; cleanup now completes reliably and the app restarts cleanly afterwards.
  • Purchase verification — fixed a spurious "revocation" error that appeared immediately after a successful in-app purchase.
  • Heart rate reading — sleep-window average is now used when available; readings outside the sleep window no longer skew the baseline.
  • Language picker — languages are now displayed in the correct alphabetical order in Settings.
  • Localisation fixes — missing translation strings for the "one-time payment" notification, credits links, and several other UI labels corrected across all supported languages.
  • Privacy Policy link — removed a duplicate link; it is now rendered as tappable inline text instead of a plain URL.
  • Advanced settings placement — the Advanced settings section is now correctly positioned below Health Connect.
  • Edge-to-edge rendering — fixed status and navigation bar colours on Android 15+.
